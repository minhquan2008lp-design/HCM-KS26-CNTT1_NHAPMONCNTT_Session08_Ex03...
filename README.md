# Phần 2. So sánh & Đánh giá

| Tiêu chí | Markdown (.md) | HTML (.html) |
| :--- | :--- | :--- |
| **Định nghĩa** | Ngôn ngữ đánh dấu nhẹ (lightweight markup language), tạo ra để dễ viết và dễ đọc. | Ngôn ngữ đánh dấu siêu văn bản (Hypertext Markup Language), dùng để xây dựng cấu trúc trang web. |
| **Cú pháp** | Rất tối giản, gọn gàng (ví dụ: dùng `#` cho tiêu đề, `**` cho in đậm). | Dài và chi tiết hơn với cặp thẻ đóng/mở (ví dụ: `<h1>Tiêu đề</h1>`, `<strong>In đậm</strong>`). |
| **Khả năng hiển thị** | Mở và đọc trực tiếp dạng thô trên mọi trình soạn thảo văn bản. | Cần hiển thị hoặc biên dịch thông qua trình duyệt web để thấy đúng định dạng. |
| **Mức độ kiểm soát** | Hạn chế, chỉ hỗ trợ các thành phần cơ bản (tiêu đề, danh sách, bảng, liên kết). | Cực kỳ chi tiết, kiểm soát sâu về cấu trúc, thuộc tính, và kết hợp tốt với CSS/JavaScript. |
| **Tối ưu Token (cho AI)** | Cực kỳ tiết kiệm (giảm 68–87% token so với HTML), xử lý nhanh hơn. | Tốn nhiều token hơn, thời gian AI sinh mã lâu hơn (gấp 2–4 lần). |
| **Ứng dụng chính** | Viết tài liệu (README trên GitHub), ghi chú, viết blog nhanh, bài viết kỹ thuật. | Xây dựng giao diện trang web, ứng dụng web chuyên sâu. |
